# K-12 Open Content Exchange (K12 OCX) Specification

K-12 OCX is a specification for publishing OER (Open Educational Resources) on the web and packaging that OER for exchange with other parties.

Typically the OER will be aggregated into collections of curriculum, content and material (compare with a book or collection of courseware).

This specification comprises the following features:

- [01_ontology.md](docs/01_ontology.md) - An ontology, which is the conceptual model used by K12 OCX to define what is being transferred.

- [02_binding.md](docs/02_binding.md) - Rules for binding that ontology onto JSON files.

- [03_packaging.md](docs/03_packaging.md) - A packaging format for OCX JSON files, allowing one to transfer OCX bundles that can represent entire curricula.

- [04_extensions.md](docs/04_extensions.md) - OCX-specific extensions to the ontology, including Representation.

- [05_representation_formats.md](docs/05_representation_formats.md) - Format-specific schemas for content referenced by Representations.

In addition, we provide:

- [examples](examples/README.md) - Examples for OCX data.

- [ocx-tools](ocx-tools/README.md) - Tools for working with OCX files.
